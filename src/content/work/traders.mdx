## Context

Traders is an educational web game that teaches business acumen, made with Mirqah. It needed a visual refresh.

## The problem

The text in Traders was baked into the artwork. Every copy change or font swap meant redrawing assets. So the real job wasn’t making the game prettier, it was making it maintainable.

## Decisions

### Turn baked-in text into real text

I converted artwork text into real text fields across the game. Fonts and copy can now change without new art, which also lays the groundwork for localisation.

### Redesign the core screens

I redesigned the three core screens: the storefloor, the peakrow and the corkboard.

### Teach the game through tutorials

I designed the tutorial flows, including a variant for the corkboard, which renders differently from the main screen.

### Ship assets engineering can use

I produced the tradeshow icon set and ran handoff with engineering in Figma.

## The product angle

This was systems thinking under real constraints. I scoped around a Figma tooling limit, sequenced the work with engineering, and chose the change that would pay off longest, maintainable text, over the quickest cosmetic win.
